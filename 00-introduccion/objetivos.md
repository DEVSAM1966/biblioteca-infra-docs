# 🎯 Objetivos de la Documentación

## 📌 Propósito
Esta documentación tiene como objetivo describir de forma clara, ordenada y profesional todos los pasos necesarios para desplegar los proyectos de la Biblioteca en dos entornos distintos:

- AWS (Amazon Web Services)
- ORACLE (Oracle Cloud)
- VPS compartido

## 🎯 Objetivos principales
- Definir los requisitos técnicos de cada entorno.
- Documentar la instalación de dependencias y herramientas previas.
- Explicar la configuración del dominio www.codigojava.com.
- Proporcionar guías de despliegue para los tres proyectos:
  - Backend Java (Spring Boot)
  - Backend Node.js
  - Frontend React
- Comparar AWS vs VPS en términos de:
  - Costes
  - Complejidad
  - Escalabilidad
  - Mantenimiento
- Crear una base documental que permita a cualquier colaborador replicar la instalación.

## 🧭 Alcance
Esta documentación cubre:
- Infraestructura
- Configuración del servidor
- Seguridad básica
- Scripts de automatización
- Buenas prácticas de despliegue

No cubre:
- Desarrollo de nuevas funcionalidades
- Diseño de arquitectura interna de los proyectos
