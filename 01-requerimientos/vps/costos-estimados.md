# 💰 Costos Estimados en VPS

El despliegue en un VPS es la opción más económica para ejecutar la plataforma completa de la Biblioteca Online. Un único servidor puede alojar los dos backends (Java y Node.js), el frontend React y las bases de datos MySQL en contenedores Docker, siempre que cuente con los recursos adecuados.

---

## 🖥 VPS recomendado

Para garantizar estabilidad, rendimiento y margen suficiente para logs, contenedores y procesos simultáneos:

- **2 vCPU**
- **4–8 GB RAM**
- **60–80 GB SSD**
- **Ubuntu 22.04 LTS**
- **IP fija incluida**
- **Tráfico ilimitado**

---

## 💵 Precio aproximado mensual

Dependiendo del proveedor (Hetzner, OVH, Contabo, Ionos), el coste estimado es:

### **Opción mínima (válida):**
- **6–8 €/mes**
- 2 vCPU  
- 4 GB RAM  
- 40–60 GB SSD  

### **Opción recomendada (óptima):**
- **8–14 €/mes**
- 2 vCPU  
- 8 GB RAM  
- 60–80 GB SSD  

---

## 📦 Qué incluye normalmente un VPS en este rango

- IP pública fija  
- Tráfico ilimitado  
- Panel de control básico  
- Acceso SSH  
- Posibilidad de reinstalar el sistema operativo  
- Firewall integrado del proveedor  

---

## 🧠 Consideraciones finales

- El VPS es suficiente para ejecutar **todo el sistema completo**.  
- El backend Java es el que más RAM consume; por eso se recomienda 8 GB si quieres holgura.  
- Los contenedores MySQL requieren almacenamiento rápido (SSD).  
- El coste del VPS es **fijo**, sin sorpresas ni cargos adicionales.  
- Es la opción más económica frente a AWS u Oracle.
